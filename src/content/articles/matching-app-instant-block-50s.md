## はじめに：ブロックされる前に知っておきたいNG行動がある

マッチングアプリで「急に相手が消えた」「アカウントが表示されなくなった」——そんな経験をしたことはありませんか。

それは高い確率で、<strong>ブロックされています。</strong>

ブロックは相手からの「これ以上関わりたくない」という意思表示です。そしてその原因となるNG行動のほとんどは、<strong>本人が悪意なく、「これくらいいいだろう」という感覚でやっているもの</strong>です。

だからこそ気づきにくく、同じことを繰り返してしまう。

この記事では、女性が即ブロックするNG行動を10個、具体的に解説します。「自分にも当てはまるかも」と思ったものから、今日改めていきましょう。

## 即ブロックされるNG行動1：マッチング直後に外見を褒めすぎる

### どんな行動か

マッチングした直後のメッセージで「写真を見てひと目惚れしました」「とてもきれいですね」「スタイルが素敵ですね」と外見への言及を連発する。

### なぜブロックされるのか

外見を褒めること自体は必ずしも悪いことではありません。しかし<strong>マッチング直後・ファーストメッセージでの過剰な外見へのコメントは「外見しか見ていない」「軽い人」という印象を与えます。</strong>

特に「ひと目惚れ」「スタイルが素敵」といった言葉は、相手に<strong>「まだ何も知らないのに外見だけで判断している」「チャラい」という警戒感</strong>を生みます。

### どうすればよかったか

最初のメッセージは<strong>プロフィールの内容（趣味・好み・書いてあること）に触れる</strong>のが基本です。「〇〇がお好きなんですね。私も同じで……」という一言が、「ちゃんと読んでくれた人」という好印象を生みます。

## 即ブロックされるNG行動2：LINEやInstagramを早々に聞く

### どんな行動か

マッチングして数回やりとりしただけの段階で「LINEを教えてもらえますか？」「Instagramはやっていますか？」と聞く。

### なぜブロックされるのか

アプリ外への誘導は、<strong>相手に「個人情報を取ろうとしている」「アプリの安全機能を外したい」という警戒感を与えます。</strong>

マッチングアプリには、運営側による監視・通報機能があります。LINE・SNSに移行することで、その保護がなくなる。<strong>関係が浅い段階でそれを求めることは「安全な場所から出させようとしている」と感じさせます。</strong>

また「なぜこの段階で？」という違和感自体が、ブロックの引き金になります。

### どうすればよかったか

アプリ外への移行は<strong>「実際に会う約束ができてから・または関係が十分に深まってから」が自然なタイミングです。</strong>相手から「LINEを教えますよ」と言い出すまで、こちらから求めないのが原則です。

## 即ブロックされるNG行動3：返信が来ないのに連続でメッセージを送る

### どんな行動か

返信が来ていないのに「お返事いただけますか？」「見ていますか？」「お忙しいですか？」と立て続けにメッセージを送る。または、1時間・2時間おきに新しいメッセージを追加していく。

### なぜブロックされるのか

<strong>返信が来ない状況に対してメッセージを重ねることは、相手に「監視されている」「追いかけられている」という恐怖感を与えます。</strong>

相手が返信しない理由は様々です。忙しい・考え中・別のことをしている——その状況を無視して連続送信することは、<strong>「自分のペースを相手に押しつける」行為であり、もっとも素早くブロックにつながるNG行動のひとつです。</strong>

### どうすればよかったか

返信が来ない場合は<strong>待つ以外にしません。</strong>どうしても気になるなら、2〜3日以上経過した場合に限り「お忙しいですか？ゆっくりで大丈夫ですよ」と一言だけ。それ以上は送らない。それでも返信がなければ、縁がなかったと受け入れましょう。

## 即ブロックされるNG行動4：下ネタ・際どい冗談を送る

### どんな行動か

「冗談ですが」「笑えたら嬉しいんですが」と前置きしながら下ネタを送る。または、「大人の関係でもいいですよ（笑）」「そういう方面も興味あります？」などのメッセージを送る。

### なぜブロックされるのか

<strong>下ネタ・性的な内容を含むメッセージは、多くの女性に「不快・怖い・危険な人」という印象を与えます。</strong>「笑い」として受け取ってもらえる関係性ができる前にこれを送ることは、完全にアウトです。

「（笑）」をつけても、「冗談ですが」と前置きしても、内容の不快さは消えません。<strong>むしろ「自覚しながらやっている」という印象で、より悪くなることがあります。</strong>

### どうすればよかったか

性的な内容・下ネタは、<strong>マッチングアプリでのやりとりでは送ってはいけない</strong>と考えるのが安全です。どんな関係になっても、それは相手が話題にし始めるまでこちらからは絶対に出さない。

## 即ブロックされるNG行動5：「会いたい」「好きになりそう」を早々に言う

### どんな行動か

数回やりとりしただけの段階で「もう会いたいです」「なんか好きになりそう」「あなたのことが気になってしょうがない」と送る。

### なぜブロックされるのか

<strong>まだほとんど知らない相手から「好きになりそう」「会いたい」と言われることは、相手に「重い」「怖い」という感覚を与えます。</strong>

出会って間もない段階での強い感情表現は、誠実さの証明ではなく「この人は誰にでもこういうことを言うのかもしれない」「感情のコントロールができない人かもしれない」という不安を生みます。

### どうすればよかったか

好意を伝えることは悪いことではありません。しかし<strong>タイミングと言葉の強さ</strong>が問題です。「また話しましょう」「お話しできて楽しいです」という温かみのある言葉から始め、感情は関係が深まるにつれて自然に伝えていくのが正解です。

## 即ブロックされるNG行動6：断られた後に文句・嫌味を言う

### どんな行動か

デートや関係継続を断られた後に「なぜですか？」「理由を教えてください」と追及する。または「こんなに時間をかけたのに」「ひどいですね」「やはり期待するんじゃなかった」と文句・嫌味を送る。

### なぜブロックされるのか

<strong>断ることは相手の権利です。その権利を尊重せず、責めたり文句を言ったりすることは、相手に恐怖感を与えます。</strong>

「この人は感情的になる」「関わるとトラブルになるかもしれない」という印象がつくため、即ブロックだけでなく、通報にもつながる可能性があります。

### どうすればよかったか

断られたら<strong>「わかりました。お時間いただきありがとうございました」の一言で終わる</strong>のが唯一の正解です。潔く終われる人は、最後の印象も良くなります。感情的な反応は、自分の評価を下げるだけです。

## 即ブロックされるNG行動7：夜中に何度もメッセージを送る

### どんな行動か

深夜0時・1時・2時台に複数回メッセージを送る。「眠れなくて」「ふと思い出して」「起きてますか？」という内容のメッセージを深夜に送り続ける。

### なぜブロックされるのか

深夜の連続メッセージは<strong>「この人の生活リズムは自分と全然違う」「昼夜問わず連絡してくる人かもしれない」という不安を与えます。</strong>

また、起きているかどうか確認するメッセージは「相手が寝ていても自分の都合で連絡する人」という印象を強めます。<strong>相手の生活リズムを尊重できない人とは、一緒にいたくない</strong>と感じるのは自然なことです。

### どうすればよかったか

メッセージを送る時間帯は<strong>朝7時〜夜21時を目安</strong>にしましょう。それ以外の時間は、どんなに気になっても送らない。翌日に送る習慣をつけるだけで、「生活リズムが普通の人」という安心感を与えられます。

## 即ブロックされるNG行動8：写真を執拗に要求する

### どんな行動か

「もっと写真を見せてもらえませんか」「全身の写真はありますか」「他にも写真を送ってもらえると嬉しいです」と繰り返し写真を求める。

### なぜブロックされるのか

写真の執拗な要求は<strong>「外見しか見ていない」「個人情報を集めようとしている」という警戒感を強烈に与えます。</strong>

特に全身・顔のアップ・自宅の様子が写ったものなどを求めることは、相手にとって<strong>「プライバシーを侵害しようとしている」</strong>という危険信号として受け取られます。

プロフィールに載っている以上の写真を求めることは、基本的にNGです。

### どうすればよかったか

写真の要求は<strong>一切しない</strong>のが安全です。相手が「こんな写真があります」と自分から見せてくれたときにだけ、素直に喜ぶ。それ以上は求めない。相手の開示するペースを尊重することが信頼につながります。

## 即ブロックされるNG行動9：既読無視への怒りをぶつける

### どんな行動か

既読がついたのに返信が来ないとき「既読無視はやめてください」「読んだなら返してほしい」「返信するのが礼儀では」と怒りや不満をぶつける。

### なぜブロックされるのか

既読をつけることと返信することは、別の行為です。<strong>「読んだのに返さない」ことへの怒りをぶつけることは、相手の時間と行動を管理しようとする行為に見えます。</strong>

この一言でほぼ確実にブロックされます。「怒りをぶつけてくる人」という印象がつくため、それ以降の関係は完全に終わります。

### どうすればよかったか

既読無視は<strong>相手の意思表示のひとつ</strong>です。「返したくない」「今は返せない」「どう返せばいいか考えている」——どれも、相手の自由です。待つか、縁がなかったと受け入れるか。それ以外の選択肢はありません。

## 即ブロックされるNG行動10：一方的に長文の自己紹介を送りつける

### どんな行動か

マッチング直後のファーストメッセージで、自分の経歴・趣味・好きなもの・嫌いなもの・求める相手像などを詳細に書いた長文を一方的に送る。

### なぜブロックされるのか

長文の自己紹介を一方的に送ることは、<strong>「この人は自分のことを話したいだけで、私に興味がない」という印象を与えます。</strong>

また、初対面で膨大な情報を送りつけることは「重い」「距離感がおかしい」という感覚を生みます。相手はその長文を読む義務も義理もありません。<strong>「返信するのが大変」と思わせた時点で、関係が終わる可能性が高くなります。</strong>

### どうすればよかったか

最初のメッセージは<strong>短く・相手への質問を一つ含む</strong>形が基本です。「〇〇がお好きなんですね。どんなところが好きですか？」——これだけで十分です。会話は双方向であることを忘れずに。

## ブロックされないための事前チェックリスト

メッセージを送る前に、以下を確認する習慣をつけましょう。

### 内容のチェック

- [ ] 外見への過剰なコメントが含まれていないか
- [ ] LINE・SNSの交換を求めていないか
- [ ] 性的な内容・下ネタが含まれていないか
- [ ] 「会いたい」「好きになりそう」などの強すぎる感情表現が含まれていないか
- [ ] 写真の要求が含まれていないか
- [ ] 長文の一方的な自己紹介になっていないか

### 送るタイミングのチェック

- [ ] 深夜（21時以降）に送ろうとしていないか
- [ ] 相手からの返信が来ていないのに続けて送っていないか

### 感情のチェック

- [ ] 断られた後に感情的になっていないか
- [ ] 既読無視への怒りをぶつけようとしていないか
- [ ] 「返信が来ないのはなぜか」と問い詰める内容になっていないか

### 最終確認

- [ ] このメッセージを見知らぬ人から受け取ったとして、不快に感じないか
- [ ] 相手が「受け取って嬉しい」と感じる内容か
- [ ] 相手の返しやすい形になっているか

## まとめ

即ブロックされるNG行動のほとんどは、<strong>「悪意がない」「これくらいいいだろう」という感覚から生まれます。</strong>だからこそ繰り返してしまうし、なかなか気づけない。

| NG行動 | 相手が感じること |
|-------|-------------|
| <strong>外見を褒めすぎる</strong> | 外見しか見ていない・チャラい |
| <strong>LINE・SNSを早々に聞く</strong> | 個人情報を取ろうとしている・危険 |
| <strong>返信なしに連続送信</strong> | 監視されている・追いかけられている |
| <strong>下ネタ・際どい冗談</strong> | 不快・怖い・危険な人 |
| <strong>「会いたい」「好きになりそう」を早々に</strong> | 重い・怖い・感情コントロールできない |
| <strong>断られた後に文句・嫌味</strong> | 恐怖感・トラブルになりそう |
| <strong>深夜に何度もメッセージ</strong> | 生活リズムが違う・尊重されていない |
| <strong>写真を執拗に要求</strong> | プライバシーを侵害しようとしている |
| <strong>既読無視への怒り</strong> | 感情的・管理しようとしている |
| <strong>一方的な長文自己紹介</strong> | 重い・自分の話しかしない・返しにくい |

<strong>「送る前に一度だけ読み返す」「相手の立場から見る」——この習慣があるだけで、ほとんどのNG行動は防げます。</strong>

ブロックされない人は特別なことをしているわけではありません。相手への配慮を忘れないこと——それだけです。
